组织情报结论卡

主题：关键技术瓶颈正在获得更集中的责任接口，研究自治边界同时外移

组织情报结论

本窗口形成两条窄化 L3 组织结论：Google 把 GDM 的长期 AGI / 科学战略与日常模型—研究—应用经营正式分开，并把后者集中到一位直报集团 CEO 的负责人；Anthropic 把 custom silicon 从探索议题转为小型高自治团队，内部承接芯片全流程和设计权威。Google 同窗出现 Discovery Loop，说明责任集中并不意味着所有探索都内部化：部分高自主研究可以移出公司边界，通过资本、云和研究合作继续连接。样本只覆盖两家公司，不能上升为行业普遍趋势，也没有效率结果。

外部信号

  • Google：Koray 统一负责 Gemini 模型、Frontier AI research、Gemini App 与 developer teams；Demis 聚焦 Alphabet 级 AGI / 科学战略。
  • Google / Discovery Loop：四名核心人员形成独立 PBC，Google 保留投资、Cloud 和研究接口。
  • Anthropic：custom silicon 团队以少数人覆盖大范围，并明确拥有 build / buy / license、design authority 与伙伴依赖边界决策。

适用边界

  • 可能成立的前提：关键瓶颈需要跨研究、产品、基础设施或外部伙伴作高频权衡，且责任范围能够被公开验证。
  • 不可直接类比的情况：只有职位 title、产品发布、融资或单一媒体的因果叙事，没有明确权责与流程变化。
  • 需要保护的风险边界：责任集中可能减少接口，也可能扩大管理跨度和单点风险；边界外移可能增加自治，也可能造成知识与人才密度损失。

可观察指标

  • 周期指标：Gemini 模型到 App / developer teams 的发布周期；Anthropic 规格冻结、伙伴交付与 first-silicon bring-up 周期。
  • 人效指标：本窗口无可独立验证数据。
  • 质量指标：模型发布稳定性、芯片验证 / respin、软硬件接口返工与研究交接完整性；暂无结果。
  • 风险指标：关键人才离场、管理跨度过大、IP / 知识交接、设计依赖、供应商与制造伙伴集中度。

去伪存真记录

  • 职务变化不等于撤换：Hassabis 主动交出日常运营的公司口径可确认；模型延迟和竞争压力是媒体情境，未被公司确认为原因。
  • 责任集中不等于效率提高：Koray 的范围横跨模型、Frontier research、App 和开发者团队；没有周期、质量、人效或商业化结果。
  • 投资与合作不等于治理权：Google 对 Discovery Loop 的 founding investment、Cloud 与研究合作不能证明其保留人员控制或研究决策权。
  • 外部创业不等于纯粹人才保留：四名核心人员已经离开内部组织，知识交接与继任风险不能被“合作伙伴”标签抹去。
  • 招聘动作不等于完整团队：Anthropic 官方岗位证明 formal hiring 和职责设计，不能证明团队规模、负责人、预算或完整能力已经形成。
  • 目标不等于结果：Anthropic 所称更快、更高效属于计划目标；没有芯片、PPA、成本、量产或客户指标。
  • 设计芯片不等于制造芯片：岗位明确 partner-executed 与 in-house 两种可能，并涉及 foundry / ASIC / IP partners；不能写成独立制造。
  • multi-chip 不是替代供应商：Anthropic 明确 AWS、Google、Nvidia、AMD 仍将是核心扩展路径。
  • 单岗薪资不等于团队薪酬：$320,000—$485,000 只适用于 Silicon Engineer 岗位，不外推整个团队或行业薪酬。
  • 窗口内文章不等于窗口内事件：阿里、字节、腾讯 AI 办公复盘的底层动作发生在 7 月；OpenAI PERM、Apple–OpenAI 与 Anthropic CGAO 已在昨日处理。
  • 静态岗位页不算今日扩编：其他 FDE、Safety、Post-training、Agent Engineer 岗位没有可靠首发时间或组织变化证据。
  • 未检出不等于没有变化：结论只限可公开验证的严格窗口材料。
