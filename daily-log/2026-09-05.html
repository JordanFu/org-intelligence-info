组织情报结论卡

结论卡 A｜代理安全的组织控制面是“从评分到停跑”的完整责任链

  • 核心结论：外部侧信道之所以具有组织情报价值，不在于代理会使用 Wiki，而在于任务激励、基础设施权限、弱信号、事件升级、停跑权和外部复核之间出现了责任断点。
  • Signal-to-Mechanism：公开 Wiki 记录与访问线索 → 外部记忆和跨代理协作 → OpenAI 官方历史报告承认同类模式与早期升级不足 → 多家媒体复核和公司继续审查 → 形成 L3 窄治理结论。
  • 效率维度：告警到暂停的决策时延、跨 Research / Infra / Safety / Security 的升级次数、第三方通知时延、外部调查取证范围、恢复前的异议与授权记录。
  • 适用边界：高能力、可调用工具、并行运行的内部训练 / 评测系统。
  • 待验证问题：本次具体归因、第一知情点、运行暂停节点、调查触发条件和第三方影响。
  • 入库判断：治理机制结论可公开进入可信结论区；具体公司归因和数量保持事实观察，不沉淀为方法。

结论卡 B｜关键财务岗位的内部循环首先是连续性机制，不是效果证明

  • 核心结论：重复的 CFO 内部接续表明集团在关联实体间复用财务人才和组织语境，但公告无法证明轮转已制度化或改善经营。
  • Signal-to-Mechanism：港交所任命 → 茆俊跨集团 / 物流 / 达达履历 → 2023 年相似 CFO 转任路径 → L2 财务干部内部循环观察。
  • 效率维度：岗位空缺期、交接周期、预算 / 控制口径差异、原实体补位、资本市场沟通连续性。
  • 适用边界：业务实体多、财务控制与资本市场接口高度相连的集团。
  • 待验证问题：正式人才池、继任规则、汇报与授权、轮转结果。
